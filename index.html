ITT-Slot 데모 — 부산 신항 타부두 환적(ITT) 컨테이너 반출시점 예측 · 묶음 장치 추천

2026 해운/항만/물류 AX 혁신 아이디어 공모전 응모작 프로토타입 · 로그인·설치 없음 · 모든 계산은 브라우저 안에서만 수행(서버 전송 없음)

주의: 이 화면의 컨테이너·선석·반출 데이터는 모두 합성(synthetic) 데이터입니다. 실제 터미널 데이터가 아닙니다. 합성 규칙 중 “타 터미널 반입 가능 구간 60~84시간”, “반입마감~접안 간격 10~12시간”만 PNIT·HPNT 웹 공개 선석계획(접안 2026.07~09, 361항차)을 작성자가 집계한 값을 참고했습니다. 재조작 감소율 등 이 화면의 모든 수치는 시뮬레이션 결과이며 실제 효과를 보장하지 않습니다.

① 데이터 — 합성 ITT 컨테이너 생성 / CSV 입출력

가상의 양하 터미널 A의 1개 블록(12베이×6열×최대 5단)에, 24시간 동안 양하되는 타부두 환적 컨테이너를 만듭니다. 각 컨테이너는 다른 터미널(가상 T-B~T-E)의 연결 모선이 정해져 있고, 그 모선의 반입 가능 구간 안에서 셔틀 트럭이 가져갑니다.

연결 모선(가상) 반입 가능 구간

컨테이너 목록 (앞 60건)

CSV 열: id, discharge_h, dest, call_id, type(GP/RF/DG), dg_class, weight(L/M/H), hc(0/1). 올린 CSV는 브라우저 메모리에서만 쓰입니다. 실제 반출시각(actual_pickup_h)은 합성 정답값이며, 실제 운영에서는 사후에만 알 수 있습니다.

② 반출시점 예측 — 타 터미널 반입 구간 + 과거 패턴

예측 방법(데모): 합성 과거 이력 3,000건으로 “목적 터미널 × 양하 시간대”별로 반입 구간 안의 반출 위치 비율 분위수(P10/P50/P90)를 학습합니다. 비교 기준은 ‘반입마감 24시간 전 일괄 반출’ 가정입니다. 실제 PoC에서는 그래디언트 부스팅 분위수 회귀로 바꿀 예정입니다.

③ 블록 맵 — 추천 장치 위치

배치안: 스택을 누르면 단별 컨테이너를 봅니다.

블록 규칙(가정): 6열은 냉동 전원 플러그 열(1~4베이만), 9·12베이는 위험물(DG) 전용 구역, 11~12베이는 바닥 하중 제한으로 최대 4단, 고규격(HC) 컨테이너는 4단 이하 적재 권장. 점선 테두리 = 단수 제한 베이, 빗금 = DG 구역, 파란 밑줄 = 냉동 플러그 열.

④ 제약 점검 — 냉동 · 위험물 · 단수/높이 · 하중

하드 제약(위반 시 추천 불가): 냉동은 플러그 열, DG는 DG 구역, DG 등급 3·5.1은 같은/인접 베이 금지(이격 규칙 단순화), 베이별 최대 단수. 소프트 제약(경고): 무거운(H) 컨테이너가 가벼운(L) 컨테이너 위, HC 5단 적재. 실제 위험물 이격은 IMDG Code 분리표와 터미널 규정을 규칙 엔진에 그대로 옮겨 적용하며, AI는 규칙을 바꾸지 않습니다.

⑤ 재조작(shuffle) 비교 — 기준안 vs 추천안

기준안은 ‘목적 터미널별로 베이를 나누고 낮은 스택부터 채우는’ 규칙(예측 미사용)을 가정했습니다. 추천안은 같은 베이 구분에 예측 반출 순서(늦게 나갈 컨테이너를 아래로)를 더합니다. 두 안 모두 하드 제약을 지킵니다.

실제(합성 정답) 반출 순서대로 컨테이너를 꺼내며, 목표 컨테이너 위에 있는 컨테이너를 같은 베이의 다른 스택으로 옮길 때마다 재조작 1회로 셉니다.
