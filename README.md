# ITT-Slot 데모 (합성 데이터 전용)

2026 해운/항만/물류 AX 혁신 아이디어 공모전 응모작 프로토타입입니다.
부산 신항 타부두 환적(ITT) 컨테이너의 반출 시점을 예측하고, 예측값으로 야드 장치 위치를 추천하는 과정을 브라우저에서 보여 줍니다.

- 로그인·설치 없음. 단일 HTML, 외부 라이브러리·외부 통신 없음.
- **모든 컨테이너·선석·반출 데이터는 합성(synthetic) 데이터**입니다. 실제 터미널 데이터가 아닙니다.
- 화면의 재조작 감소율 등 수치는 시뮬레이션 결과이며 실제 효과를 보장하지 않습니다.
